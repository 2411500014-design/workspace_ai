# Rampung: mode presets

Sebuah mode adalah konfigurasi, bukan kode: template project, istilah UI, persona AI, fitur khusus, dan skema ekstraksi dokumen. Setiap mode disimpan sebagai file YAML berversi di folder ini. **Belum ada file.**

Urutan: `academic` (MVP) → `research` (V1) → `developer`, `work`, `personal` (V2).

Karena Rampung dua bahasa, setiap teks yang dilihat pengguna di preset punya versi `id` dan `en`. Lihat catatan vault `Produk/Mode sebagai Preset.md` dan `UX/Bilingual ID-EN.md`.
